# job_search_course_work

## Описание:

job_search_course_work - это программа, которая будет получать информацию о вакансиях с платформы hh.ru в России,
сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/RomanBatyuk/job_search_course_work
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

1. Откройте проект в PyCharm.
2. Теперь вы можете поучавствовать в учебном процессе ;)
3. Для тестирования функционала обратитесь к директории tests в корне проекта.

## Функционал:

В корне проекта модуль main, запускает работу программы.

В директории src:

* iteraction_with_api - модуль для взаимодействия с API.
* iteraction_with_file - модуль для взаимодействия с файлами.
* iteraction_with_vacancies - модуль взаимодействия с вакансиями.
* auxiliary_function - вспомогательные функции.
